# LiFE — React site (department/event pages)

This repository contains a React frontend (bootstrapped with Create React App) used to serve LiFE event pages. It includes routes per-year (for example `/2024`, `/2025`) and a shared `Layout` which reads the year from the URL to render the site title.

## Quick summary

- Project: LiFE event site (React)
- Key behavior: The page title in the header shows `LiFE {year}` and the year is taken from the path (any 4-digit year segment).
- Where to change the year-handling logic: `src/assets/pages/Layout.jsx`

## Folder overview (important paths)

- `public/` — static HTML and favicons used by CRA
- `src/` — application source code
  - `src/assets/pages/Layout.jsx` — top-level layout used across routes; extracts year from `location.pathname`
  - `src/index.js` / `src/App.js` — app entry and routing (look here if you need to change routes)
  - `src/assets/images/` — images used in the header and pages
- `build/` — production build output (generated by `npm run build`)

## Running locally

Requirements: Node.js and npm installed (project was developed with a standard Create React App toolchain).

1. Install dependencies

```bash
npm install
```

2. Run the development server

```bash
npm start
```

This opens the app in development mode. By default CRA uses port 3000; if you run on a different port (for example your setup uses 8080) the path-based year behavior still works — just open `http://localhost:8080/2024` (or change the port in your environment).

3. Build for production

```bash
npm run build
```

Produced files are written to `build/` and are ready to deploy to static hosting.

## How routes and year extraction work

The shared layout component `src/assets/pages/Layout.jsx` reads the current location using React Router's `useLocation()` hook and extracts the first 4-digit segment (regex `/^\\d{4}$/`). Example behavior:

- Visiting `/2024/` → header shows `LiFE 2024`
- Visiting `/2025/` → header shows `LiFE 2025`
